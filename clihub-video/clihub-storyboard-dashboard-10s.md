# clihub: 10s dashboard cut (loop)

Build: `clihub-video/prototype-cut` (`npm run embed` writes `public/showcase/clihub.html`). Screens come from Figma *Portfolio* (the API Gateway host stats) and are shown as a working prototype, as in the 20s cut.

**Brief (Anu, round 4):** combine ssh-showcase_5 with the current cut, at 10 seconds. Show the dashboard; everything else is minor. Grey background only, no drop shadows.

- **Background:** grey only. A soft radial gradient on the swatch `#B9C7DB`, a slow drifting light and faint grain. No lilac and no purple glow.
- **Shadows:** none, on the dashboard, callouts, cursor or headline pill. The dashboard edge is a 1px light border.
- **Headline:** from ssh-showcase_5, "Everything about a server, one tab away." It sits under the pill "SSH CLIENT · HOST STATS"; the words rise out of masks.

| Time | Beat | Visuals |
|---|---|---|
| 0.0–1.0 | Dashboard rises | The API Gateway stats dashboard (Overview tab) rises from a 14° tilt with a blur, and the headline rises word by word. |
| 1.0–2.5 | Overview | Callout: Uptime 15 days, 6 hours · Connected. |
| 2.5–4.5 | Performance | The cursor clicks Performance and the underline slides. Callout: Total CPU Usage ring counting to 45% (Intel Xeon E5-2676 v3). |
| 4.5–6.5 | Storage | The cursor clicks Storage. Callout: Used Storage counting to 184 GB of 200 GB. |
| 6.5–9.1 | Network | The cursor clicks Network. Callout: Eth0 Download 1.1 / Upload 1.6 MB/s with live bars. |
| 9.1–10.0 | Loop | The dashboard pushes past the lens with a blur and the loop restarts. |

Everything is on one slow camera push. Tab switches are staggered (the new tab leads and the old one clears fast), so screens never ghost.

## Taken from each source
- **Current cut (20s lineage):** the real Stats screens, tab switching, the cursor, the metric callouts and the zoom-through.
- **ssh-showcase_5:** the dashboard-first story (stats across tabs with small callouts) and the headline.
- **Left out to keep it to 10s:** the vault hook, Connect, Terminal + Ask AI, SFTP and Port mapping.
