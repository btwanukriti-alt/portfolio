# College ERP mockup modules (HTML to JPEG)

Source for `public/case-studies/college-management/01..09-*.jpg`.

- `screens.js` + `styles.css`: the redesigned Finance, Staff and drawer screens as HTML (sample data).
- `modules.html`: the gallery modules (plates, desktop frames, colour blocks, dashed callouts).
- `render.mjs`: `node render.mjs <abs path to modules.html> <out dir> <abs path to public/case-studies/college-management/mockups/>`. The last folder holds the earlier-version screenshots used by module 9.
